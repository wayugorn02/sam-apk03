วิธีนำแอป "แซม" ไปทำเป็นไฟล์ APK และเชื่อมต่อ API

ขั้นตอนที่ 1: เปิดใช้งาน Google Drive API (สำหรับดึงและอัปโหลดไฟล์จริง)

  1. เข้าไปที่ Google Cloud Console สร้างโปรเจกต์ใหม่ และเปิดใช้งาน Google Drive API
  2. ไปที่เมนู Credentials → Create Credentials → OAuth client ID (เลือกชนิด Web application หรือ Android)
  3. นำค่า Client ID มาวางในปุ่ม "2 บัญชี → ล็อกอิน Google Drive API จริง" ของแอปนี้เพื่อลิงก์หลายบัญชีพร้อมกันได้เลย

ขั้นตอนที่ 2: การแปลงเว็บแอปนี้เป็นไฟล์ Android (.apk)

  • วิธีที่เร็วที่สุด (CapacitorJS / Android Studio): ห่อไฟล์เว็บแอปนี้ด้วย Capacitor (`npx cap add android`) พร้อมตั้งชื่อแอปว่า แซม และใช้ไฟล์ไอคอนที่คุณอัปโหลดสั่ง Build APK ใน Android Studio
  • เขียนเป็น Native / Flutter: หากคุณลองเล่นเว็บแอปต้นแบบนี้แล้วถูกใจครบทุกฟังก์ชัน แจ้งผมได้เลยครับ เดี๋ยวผมสร้างไฟล์โค้ดสำหรับนำไปคอมไพล์เป็น APK ให้ทันที
